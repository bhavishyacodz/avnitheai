# AI Command Center

A phone-first personal AI command center built with GitHub Codespaces.

## Current Phase

Phase 0.1

## Current Features

- Express backend
- Single-page command interface
- Health endpoint
- Stub tool router
- JSON command endpoint

## Architecture

User
↓
Frontend
↓
Express Backend
↓
Tool Router
↓
Agents (future)

## Planned Agents

- Claude / Anthropic API
- GitHub
- WhatsApp Business Platform
- Telegram
- Other supported integrations

## Development

Install dependencies:

npm install

Run development server:

npm run dev

Run production server:

npm start
